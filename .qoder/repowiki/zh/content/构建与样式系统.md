# 构建与样式系统

## 构建工具链

### Vite 插件链

| 插件 | 作用 | 平台条件 |

### TailwindCSS 配置

#### 语义色映射（tailwind.config.js）

所有色值通过 CSS 变量间接引用，不硬编码具体色值：

| Tailwind 类 | CSS 变量 | 语义 |
|-------------|----------|------|
| text-primary / bg-primary | --color-primary | 主色 |
| text-theme-text / bg-theme-text | --text-color | 主题文字色 |
| text-theme-bg / bg-theme-bg | --bg-color | 主题背景色 |
| text-theme-border / border-theme-border | --border-color | 主题边框色 |
| text-success / bg-success | --color-success | 成功色 |
| text-warning / bg-warning | --color-warning | 警告色 |
| text-error / bg-error | --color-error | 错误色 |

暗黑模式通过 `darkMode: 'class'` 实现。

### CSS 处理栈

```
PostCSS (vite.config.js 中配置)
  └── tailwindcss → autoprefixer
```

> `postcss.config.js` 已注释废弃，其中包含曾经使用的 `postcss-pxtransform`（px 转 rpx）配置，目前仅保留作参考。

### 自动导入

通过 `unplugin-auto-import` 自动导入 Vue 和 uni-app API：

```javascript
AutoImport({
  imports: ['vue', 'uni-app'],
  dts: 'typings/auto-imports.d.ts',
})
```

项目中可直接使用 `ref`、`computed`、`watch`、`onMounted` 等，无需手动 import。

## 变量体系

### CSS 变量（运行时可切换）

- `--color-primary` / `--color-primary-light` / `--color-primary-dark` / `--color-primary-disabled` — 主色系
- `--text-color` / `--text-color-grey` — 文字色
- `--bg-color` / `--bg-color-grey` — 背景色
- `--border-color` — 边框色
- `--u-*` — uView Pro 基础变量（main-color/content-color/tips-color 等）

### SCSS 变量（编译时固定）

定义于 `common/css/uni.scss`：

| 类别 | 变量 | 值 |
|------|------|-----|
| 字号-sm | $uni-font-size-sm | 24rpx |
| 字号-base | $uni-font-size-base | 28rpx |
| 字号-lg | $uni-font-size-lg | 32rpx |
| 圆角-base | $uni-border-radius-base | 6rpx |
| 水平间距 | $uni-spacing-row-base | 20rpx |
| 垂直间距 | $uni-spacing-col-base | 16rpx |

还有文章场景色调（title/subtitle/paragraph）和过渡类（fade-enter-active 等）。

### 页面基础样式（core.scss）

- `.page` 类：背景 `#f7f7f7`，flex 列布局，全高（`!important`）
- `.pb-env` 类：底部安全区适配（`env(safe-area-inset-bottom)`）
- 自定义字体 `oxanium`（来自 `static/font/Oxanium-Bold.ttf`）
