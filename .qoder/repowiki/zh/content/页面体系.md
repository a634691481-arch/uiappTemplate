# 页面体系

## 路由机制

页面路由由 `a-hua-auto-pages-json` Vite 插件自动扫描 `pages/` 目录的文件系统生成 `pages.json`。创建/删除 vue 文件即自动更新路由，无需手动编辑 `pages.json`。

全局配置：
- `navigationStyle: "custom"` — 自定义导航栏，所有页面不使用原生导航栏
- `disableScroll: true` — 默认禁止页面滚动
- `enablePullDownRefresh: false` — 默认禁止下拉刷新

## TabBar 页面（4 个）

| 路由 | 名称 | 说明 |
|------|------|------|
| `pages/index/index` | 首页 | 应用入口首页 |
| `pages/tourGuide/index` | 旅游/导游 | 导游导览模块 |
| `pages/consult/index` | 咨询 | 咨询模块 |
| `pages/my/index` | 个人中心 | 用户中心入口 |

TabBar 通过自定义 `yy-tabbar` 组件渲染，数据来自 Vuex `$tabbar` 模块。图标使用 RemixIcon（通过 zero-icon 组件加载）。

## 登录流程

登录页位于 `pages/login/index`，跳转流程：

```
未登录用户访问需登录页面
  → vk-unicloud 拦截器检测 checkTokenPages
    → 调用 interceptor.login 回调
      → myfn.navigateToLogin('/pages/login/index')
        → vk.navigate.setOriginalPage 保存当前页面 URL
          → 跳转登录页
            → 登录成功后 vk.navigateBack 到原始页面
```

## 分包加载

`pages_sub/` 目录作为分包，包含：
- `pages_sub/index/index` — 子包首页
- `pages_sub/index/city-select` — 城市选择（自定义导航栏）

## 错误页面

两处错误页面：
- `pages/error/404/404` — 404 错误页（主路径）
- `pages/error/404` — 别名路径

通过 `App.vue` 的 `onPageNotFound` 生命周期自动重定向到错误页。
