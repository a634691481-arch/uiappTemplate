# 组件体系

## 概述

项目包含 14 个自定义业务组件（`yy-*` 前缀），均位于 `components/` 目录。通过 `pages.json` 中的 easycom 配置自动注册：

```json
"easycom": {
  "autoscan": true,
  "custom": {
    "^yy-(.*)": "@/components/yy-$1.vue"
  }
}
```

使用时直接以 `<yy-paging>`、`<yy-empty>` 等形式引用，无需手动 import。

## 组件分类

### 1. 分页体系（z-paging 封装层）

基于 z-paging 组件库的上层封装，提供统一的列表页开发体验：

| 组件 | 职责 |
|------|------|
| `yy-paging` | 分页列表核心封装（339 行），包裹 z-paging |
| `yy-refresher` | 自定义下拉刷新视图（GIF 动画 + 状态文字） |
| `yy-loading` | 加载中状态 |
| `yy-empty` | 空状态占位（SVG 图标 + 提示文字，支持点击重载） |
| `yy-nomore` | "没有更多数据"底部提示 |

`yy-paging` 调用方式：

```html
<yy-paging ref="paging" v-model="list" @query="queryData">
  <yy-paging>
    <view v-for="item in list">{{ item.name }}</view>
  </yy-paging>
</yy-paging>
```

数据加载完成后调用 `paging.value?.complete(data)`。

### 2. 主题选择体系

| 组件 | 职责 |
|------|------|
| `yy-theme-picker` | 主题颜色选择器，底部弹窗展示 9 套主题色选项 |
| `yy-dark-mode-picker` | 深色模式选择器，基于 u-popup 底部弹窗 |

均使用 uView Pro 的 `useTheme()` API 实现运行时切换。

### 3. 导航与交互

| 组件 | 职责 |
|------|------|
| `yy-tabbar` | 底部 Tab 导航栏，基于 u-tabbar，数据从 Vuex `$tabbar` 获取 |
| `yy-picker-modal` | 通用底部选择器弹窗，带标题 + 关闭按钮，最大高度 60vh |
| `yy-tip-modal` | 提示信息弹窗，带装饰线标题 |
| `yy-edit-information` | 编辑用户信息弹窗（昵称、头像） |

### 4. 工具组件

| 组件 | 职责 |
|------|------|
| `yy-upload` | 图片/视频上传（313 行），网格布局，支持删除、上传进度 |
| `yy-icon` | 图标组件，基于 u-image 加载远程/本地图片图标 |
| `yy-noNetwork` | 无网络全屏覆盖提示，提供重试按钮 |

## 组件设计原则

1. **单一职责** — 每个组件只做一件事（yy-empty 只做空态，yy-loading 只做加载）
2. **极简依赖** — 业务组件通过 props 接收数据，不直接调用 API
3. **样式统一** — 使用 TailwindCSS 语义类 + 统一间距（p-3 / gap-3）
4. **平台兼容** — 条件编译处理跨平台差异（如 yy-icon 的图片加载策略）
