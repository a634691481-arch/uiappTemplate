# 项目概览

## 基本信息

- **项目名称**：它思乐游
- **版本**：v1.0.9（versionCode 9）
- **项目类型**：uni-app 跨端模板项目（uniCloud 云开发全栈模板）
- **应用描述**：旅游/钓鱼类实用工具应用，涵盖天气查询、钓鱼指数、地图钓点、拍照识鱼、鱼类百科等功能
- **AppID**：`__UNI__CA8E78B`

## 技术栈全景

| 层次 | 技术选型 |
|------|---------|
| 框架 | uni-app (Vue 3) — 跨端开发框架 |
| UI 库 | uView Pro — 99+ 组件，通过 easycom 自动注册 |
| 状态管理 | Vuex（3 个命名空间模块：`$app` / `$user` / `$tabbar`） |
| HTTP 客户端 | `uni.$u.http`（uView Pro 内置，非 axios） |
| 后端 | vk-unicloud — uniCloud 云开发全栈框架 |
| 样式 | TailwindCSS v3.4 + SCSS |
| 分页 | z-paging（封装为 yy-paging） |
| 图标 | zero-icon（基于 Iconify）+ u-icon（uView Pro 内置） |
| 构建 | Vite + @dcloudio/vite-plugin-uni |

## 目录结构

```
tasi_h5/
├── apis/                  # HTTP 通信层（环境配置 + 拦截器）
├── common/
│   ├── css/               # 全局样式（core.scss + uni.scss）
│   └── function/          # 公共工具函数 + 主题配置
├── components/            # 14 个 yy-* 自定义业务组件
├── pages/                 # 28 个页面（4 tabbar + 24 子页）
│   ├── index/             # 首页（TabBar）
│   ├── tourGuide/         # 旅游/导游（TabBar）
│   ├── consult/           # 咨询（TabBar）
│   └── my/                # 个人中心（TabBar，20 个子页）
├── pages_sub/             # 分包页面
├── store/                 # Vuex 状态管理
├── uni_modules/           # uni_modules 第三方包
├── static/                # 静态资源
├── app.config.js          # 全局配置中心
├── App.vue                # 根组件
├── main.js                # 应用入口
├── pages.json             # 页面路由
├── theme.json             # 亮/暗主题配色
└── vite.config.js         # 构建配置
```

## 自定义组件（yy-* 前缀）

共 14 个，通过 easycom 自动注册（`^yy-(.*)` → `@/components/yy-$1.vue`）：

| 组件 | 用途 |
|------|------|
| yy-paging | 分页列表封装（基于 z-paging） |
| yy-empty | 空状态占位 |
| yy-loading | 加载动画 |
| yy-nomore | "没有更多数据"指示器 |
| yy-refresher | 自定义下拉刷新视图 |
| yy-upload | 图片/视频上传 |
| yy-icon | 图标组件 |
| yy-tabbar | 底部导航栏 |
| yy-picker-modal | 通用选择器弹窗 |
| yy-tip-modal | 提示信息弹窗 |
| yy-theme-picker | 主题颜色选择器 |
| yy-dark-mode-picker | 深色模式选择器 |
| yy-edit-information | 编辑用户信息弹窗 |
| yy-noNetwork | 无网络提示页 |

## 核心文件索引

| 文件 | 职责 |
|------|------|
| `main.js` | 应用入口，按序注册 store / uView Pro / vk-unicloud / HTTP 层 |
| `App.vue` | 生命周期钩子 + 全局样式入口 |
| `app.config.js` | vk-unicloud 配置中心 |
| `apis/http.api.js` | HTTP 环境配置 + API 定义 |
| `apis/http.interceptor.js` | 请求/响应拦截器 |
| `store/modules/$app.js` | 应用级状态管理 |
| `store/modules/$user.js` | 用户状态管理 |
| `store/modules/$tabbar.js` | 底部导航状态管理 |
