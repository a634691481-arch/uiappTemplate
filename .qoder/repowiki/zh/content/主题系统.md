# 主题系统

## 架构概述

项目采用双重主题架构：

1. **uView Pro 主题色**（业务语义色）— 9 套主题色板，每套 20 个色值，控制按钮/输入框/标签等组件的主色
2. **Light/Dark 模式**（页面框架色）— 控制导航栏、tabbar、背景色等页面整体色调

两层互相独立又通过 CSS 变量桥接。

## 9 套主题色

定义于 `common/function/uview-pro.theme.js`，每套包含 primary / error / warning / success / info 五种语义色，各自附带 Light / Dark / Disabled 变体。

| 主题名 | 标签 | 主色值 |
|--------|------|--------|
| purple | 霞光紫 | #7c3aed |
| green | 清翠绿 | #059669（**默认**） |
| orange | 暖阳橙 | #f97316 |
| dark | 午夜蓝 | #0b3d91 |
| pink | 樱花粉 | #ec4899 |
| blue | 天空蓝 | #3b82f6 |
| teal | 薄荷青 | #14b8a6 |
| coral | 珊瑚红 | #ff6b6b |
| amber | 琥珀金 | #d97706 |

## 运行时主题管理

通过 uView Pro 的 `useTheme()` 钩子在 `App.ku.vue` 中管理：

```javascript
const { darkMode, themes, currentTheme } = useTheme()
```

`<u-config-provider>` 组件接收三个 props：
- `dark-mode` — 是否暗黑模式
- `themes` — 主题列表（来自 theme.js）
- `current-theme` — 当前主题名

组件内部动态生成 CSS 变量注入页面，实现运行时主题切换。主题变更需显式调用 uView Pro 的 theme API 触发组件重渲染。

## Light / Dark 双模式

定义于 `theme.json`：

| 模式 | 背景色 | 导航栏 | 文字色 |
|------|--------|--------|--------|
| light | #fcfcfc | #fcfcfc | #333333 |
| dark | #181818 | #181818 | #ffffff |
| 选中色 | — | #ff6b00（两模式相同） | — |

暗黑模式通过 TailwindCSS 的 `darkMode: 'class'` 实现，当 `<html>` / `<page>` 元素添加 `class="dark"` 时，`dark:` 前缀的 Tailwind 类生效。

## CSS 变量桥接

TailwindCSS 语义色全部映射到 CSS 变量：

| Tailwind 类 | CSS 变量 |
|-------------|----------|
| text-primary / bg-primary | --color-primary |
| text-theme-text / bg-theme-text | --text-color |
| text-theme-bg / bg-theme-bg | --bg-color |
| text-theme-border / border-theme-border | --border-color |

这些 CSS 变量在 uView Pro 主题切换时自动更新，所有引用 CSS 变量的元素同步响应。

## 样式导入链

```
uni.scss
  ├── uni_modules/uview-pro/theme.scss  (--u-* CSS 变量)
  └── common/css/uni.scss               (尺寸/圆角变量)

App.vue <style>
  ├── uni_modules/uview-pro/index.scss  (uView 组件样式)
  ├── tailwindcss/base/utilities/components
  └── common/css/core.scss              (页面布局+安全区+字体)
```

## 访问方式

- 运行时获取主色：`uni.$u.color.primary`
- 主题切换组件：`yy-theme-picker`（主题色选择器）、`yy-dark-mode-picker`（深色模式选择器）
- 开关组件：`u-switch` 绑定 `darkMode` 状态
