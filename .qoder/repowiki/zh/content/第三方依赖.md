# 第三方依赖

## uni_modules 插件

| 包名 | 版本 | 用途 |
|------|------|------|
| **uview-pro** | — | 核心 UI 组件库，99+ 组件，提供 u-popup / u-tabbar / u-image / u-icon 等基础组件及 useTheme / useLocale hooks |
| **vk-unicloud** | — | uniCloud 云开发全栈框架，提供 vk 全局对象（vk.toast / vk.navigateTo / vk.vuex / vk.getVuex 等工具方法） |
| **z-paging** | — | 分页/下拉刷新/滚动加载组件库，被 yy-paging / yy-refresher / yy-nomore 封装使用 |
| **uni-id** | — | uni-id 用户身份认证系统（云函数公共模块），处理微信登录、token 管理等 |
| **uni-config-center** | — | uni-app 配置中心（云函数公共模块） |
| **liu-slide-img** | — | 图片滑动验证组件 |

### 注册方式

- **uview-pro**：`app.use(uViewPro, { theme: { themes, defaultTheme: 'green', defaultDarkMode: 'light' } })`
- **vk-unicloud**：`app.use(vk, config)`（config = app.config.js）
- **z-paging**：全局分页大小在 main.js 设置 `uni.$zp.config['default-page-size'] = 12`
- **组件自动注册**：通过 pages.json easycom 配置，`^u-(.*)` 自动匹配 uview-pro 组件

## 包管理器

pnpm 为首选（存在 pnpm-lock.yaml），npm 为备用（存在 package-lock.json）。

关键配置：
- `pnpm.overrides`：`@iconify/utils@2.1.33`（锁定版本）
- `postinstall`：`"weapp-tw patch"` — 安装依赖后自动修补 TailwindCSS 以兼容小程序
