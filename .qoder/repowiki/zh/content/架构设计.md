# 架构设计

## 整体架构分层

```
┌─────────────────────────────────────────────┐
│                App.vue                       │
│   生命周期管理 / 全局样式 / 主题注入           │
├─────────────────────────────────────────────┤
│              main.js 入口                    │
│   store → uViewPro(theme) → vk-unicloud     │
│        → http.interceptor → http.api         │
├─────────────┬───────────────┬───────────────┤
│  UI 层      │  业务逻辑层    │  数据层       │
│  uView Pro  │  pages/       │  Vuex         │
│  yy-* 组件  │  components/  │  $app / $user │
│  TailwindCSS│               │  / $tabbar    │
├─────────────┴───────────────┴───────────────┤
│            HTTP 通信层 (apis/)               │
│  请求拦截(token/时间戳/平台) → 响应拦截(状态码分发)│
├─────────────────────────────────────────────┤
│          vk-unicloud 云开发框架              │
│    uniCloud 云函数 (router) → 数据库/存储     │
└─────────────────────────────────────────────┘
```

## 启动流程

应用启动时的依赖注入顺序（定义于 `main.js`）：

1. **创建 Vue 应用** — `createApp(App)`
2. **注册 Vuex Store** — `app.use(store)`
3. **导入 app.config.js** — 获取全局配置对象
4. **导入主题配置** — `uview-pro.theme.js`（9 套主题色值）
5. **注册 uView Pro** — `app.use(uViewPro, { theme: { themes, defaultTheme: 'green', defaultDarkMode: 'light' } })`
6. **注册 vk-unicloud** — `app.use(vk, config)`（传入 app.config.js 作为配置）
7. **安装 HTTP 拦截器** — `app.use(httpInterceptor)`
8. **注册 API 定义** — `app.use(httpApi)`
9. **设置 z-paging 全局分页大小** — `uni.$zp.config['default-page-size'] = 12`
10. **挂载应用** — `app.mount('#app')`

## 数据流

```
用户操作 → vk.navigateTo(含登录检查)
  → API 请求 (api.xxx(params))
    → http.interceptor 添加 Authorization / x-timestamp / x-client-platform
      → 后端响应
        → http.interceptor 状态码分发 (0失败 / 1/200成功 / 401重新登录 / 403无权限 / 500服务器错误)
          → Store action 更新 state (自动持久化到 lifeData)
            → UI 更新
```

## 主题系统架构

双重主题架构：

1. **uView Pro 主题色**（业务主色）：9 套主题，每套 20 个色值，通过 `uni.$u.color.primary` 运行时访问
2. **Light/Dark 模式**（页面框架色）：`theme.json` 定义导航栏/tabbar 的亮暗配色，通过 CSS 变量注入
3. **TailwindCSS 桥接**：所有语义类（`text-primary` / `bg-theme-bg` 等）映射到 CSS 变量，运行时动态切换

## 路由机制

- 页面路由由 `a-hua-auto-pages-json` Vite 插件自动扫描 `pages/` 目录文件系统生成 `pages.json`
- 全局 `navigationStyle: "custom"`（自定义导航栏）
- 4 个 tabbar 页面（index / tourGuide / consult / my），通过 yy-tabbar 组件渲染
- 登录校验：`checkTokenPages` 白名单机制（mode: 2 = list 内免登录，list 外需登录）

## 状态持久化

Vuex 状态通过 `saveLifeData` 自动持久化到 `uni.setStorageSync('lifeData')`：
- 应用重启时从 `lifeData` 恢复模块状态
- `$error` 模块被排除（`notSaveStateKeys`）
- 所有状态变更统一通过 `updateStore` mutation（支持点号路径深层次更新）
