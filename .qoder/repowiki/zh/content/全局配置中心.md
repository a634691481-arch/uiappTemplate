# 全局配置中心

## 概述

`app.config.js` 是项目全局配置中心，作为 vk-unicloud 框架的配置对象注入。集中管理路由、CDN、登录校验、分享、云存储、错误码等所有运行时配置。

## 核心配置项

| 配置 | 值 | 说明 |
|------|-----|------|
| `debug` | `process.env.NODE_ENV !== 'production'` | 非生产环境启用调试 |
| `functionName` | `'router'` | 云函数名称 |
| `imageUrl` | `http://cdn.diaodiandaren.com` | 图片 CDN 域名 |
| `targetTimezone` | `8` | 目标时区（东八区） |
| `index.url` | `/pages/index/index` | 首页路径 |
| `login.url` | `/pages/login/index` | 登录页路径 |
| `error.url` | `/pages/error/404/404` | 错误页路径 |
| `color.main` | `#ff4444` | 主色 |
| `color.secondary` | `#555555` | 次要色 |

## 登录校验

`checkTokenPages` 配置登录校验策略：

- `mode: 2` — 白名单模式：list 内页面**不需要**登录，list 外页面**需要**登录
- 拦截失败触发 `interceptor.login` 回调

## 分享控制

`checkSharePages` 配置分享策略：

- `mode: 2` — list 内页面**不可分享**
- 配合 vk-unicloud 的分享拦截机制

## 云存储

`service.cloudStorage` 支持三提供商：

- **uniCloud 默认存储**
- **七牛云** — 扩展存储
- **阿里云 OSS** — 扩展存储

## 错误码映射

`globalErrorCode` 统一定义：

- 超时错误
- 系统错误
- 网络错误
- 自定义业务错误码（中文提示）

## 拦截器钩子

`interceptor` 对象提供可覆写的回调：

- `login` — 登录拦截后的处理逻辑
- `fail` — 请求失败后的处理逻辑

## 公共函数注入

`myfn` 字段指向 `common/function/myPubFunction.js`，通过 vk-unicloud 框架注入为 `vk.myfn.xxx`，全局可用的工具函数：

- `previewImage` / `previewImages` — 图片预览
- `copyToClipboard` — 复制到剪贴板
- `buildErrorSummary` — 构建错误摘要
- `logout` — 退出登录
- `navigateToLogin` — 跳转登录页
